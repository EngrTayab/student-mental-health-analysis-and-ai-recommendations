What is Student Mental Health Analysis?

Student Mental Health Analysis is a Machine Learning project that predicts a student's stress level based on different academic, lifestyle, social media and mental health related factors.

The application provides a simple form where users can enter their information. The trained Machine Learning model analyzes these inputs and predicts the student's stress category and provides AI Recommendations.
