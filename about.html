About This Project

A Machine Learning based web application designed to analyze student stress levels and provide useful lifestyle recommendations.

What is Student Mental Health Analysis?

Student Mental Health Analysis is a Machine Learning project that predicts a student's stress level based on different academic, lifestyle, social media and mental health related factors.

The application provides a simple form where users can enter their information. The trained Machine Learning model analyzes these inputs and predicts the student's stress category.

How It Works

1. Enter Information

Enter information such as study hours, social media usage, sleep, physical activity and mental health score.

2. Get Prediction

The trained Machine Learning model processes the provided information and predicts the student's stress level.

3. Get Recommendations

Users can click the AI Recommendations button to view recommendations based on their prediction and inputs.
